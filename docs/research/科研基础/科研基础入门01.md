刚进课题组的那段时间，真正让人手足无措的往往不是公式和代码，而是「听不懂大家在说什么」。组会上导师说「这篇先挂 arXiv，投个 CCF-A 试试」；师兄提醒「注意别一稿多投，审稿周期很长」；群里有人问「你这个是 EI 源刊还是 EI 会议」。这些词单独拆开都认识，凑在一起就是另一套语言。

这篇笔记把科研入门的「共同常识」梳理成三块：**科研领域基础知识**（论文与期刊怎么分类、有哪些趁手的工具）、**科研黑话**（大论文小论文、顶刊顶会到底指什么）、**文献检索的网站与高级检索方法**。写法上尽量落到能直接拿去用的程度，需要清单的地方给清单，需要对照的地方给表格；参考到的资料统一列在文末。

## 写在前面：为什么要先补这三块

科研的起点不是「想出一个好 idea」，而是能在一个共同体里正常工作——看懂别人在说什么，找到别人做过什么，再把自己的东西放进这个体系里。这条链条上横着三类最基础的障碍：听不懂术语，分不清刊物与会议的层级，以及面对海量文献不知道从哪儿下手。它们本身都不难，但没人事先讲一遍，就得靠一次次踩坑去换。

一个比较稳妥的顺序是先把「基础知识 + 术语 + 文献检索」补上，再谈选题与创新，因为后面几乎所有动作都要建立在这三块之上。所以这篇笔记也按这个顺序来。

## 一、科研领域基础知识

### 1.1 先分清文体：论文有哪几种

在讨论「发一篇什么级别的文章」之前，得先知道论文本身分几类。它们的写作结构、评审方式和认可度都不一样。

| 类型           | 说明                                                      | 常见载体                            |
| -------------- | --------------------------------------------------------- | ----------------------------------- |
| 期刊论文       | 发表在学术期刊上，通常经过编辑初审 + 同行评议（peer review） | SCI/SSCI 期刊、中文核心期刊         |
| 会议论文       | 围绕某场学术会议投稿，部分只收摘要，部分进入正式论文集      | 计算机顶会、IEEE 会议、CPCI 收录会议 |
| 研究论文       | 报告作者自己产生数据、得到结论的原创工作（empirical / primary） | 绝大多数期刊论文                    |
| 综述 / 调查    | 综合若干篇已有研究，做归纳、比较，甚至做元分析（meta-analysis） | Nature Reviews、Survey、CSUR 等      |
| 学位论文       | 硕士 / 博士为申请学位撰写，需通过评审与答辩                 | 大论文，见下节                      |
| 预印本 preprint | 未经同行评审、先行公开的稿子，用于抢占时间和快速传播        | arXiv、bioRxiv、SSRN、ChemRxiv       |
| 快报 / Letter  | 篇幅短、周期快，用于快速发布阶段性重要结果                  | 各学科的 Letter / Communication      |

一个常见误解是把 `DOI` 当成质量标志。**DOI 是论文的「身份证号」**，解决的是「怎么稳定地找到这篇论文」，题目可能重名、网址可能失效，但 DOI 相对稳定；它**不代表**论文质量好。有 DOI 不等于就是高水平论文。

::: note 会议与期刊谁更重要，不能脱离学科讨论

在计算机等学科，顶级会议（顶会）的认可度很高，很多重要工作先发会议再扩期刊；而在不少传统学科里，期刊论文的分量更重。看到「发在会议上」就下判断，往往会闹笑话。

:::

### 1.2 期刊的「等级」：国内、国际各有一套

「发一篇 SCI」是日常说法，但严格讲，**SCI 不是一种论文，而是一套引文索引**。我们说的「SCI 论文」，指的是发表在 SCI 收录期刊上的论文。同理，CSSCI、北大核心都是「目录 / 索引」，不是文章类型。

#### 国内体系（从低到高）

| 名称                              | 主管 / 编制单位           | 范围                   | 说明                                                          |
| --------------------------------- | ------------------------- | ---------------------- | ------------------------------------------------------------- |
| 普刊（省级 / 国家级）             | 各主办单位                | 全学科                 | 只反映主管单位层级，**国家级并不等于比省级质量高**；须在国家新闻出版署可查、有 CN 与 ISSN |
| 科技核心（中国科技论文统计源期刊） | 中国科学技术信息研究所    | 理工农医为主           | 门槛高于普刊，目录每年更新，变动较大                          |
| 北大核心（《中文核心期刊要目总览》） | 北京大学图书馆            | 全学科                 | 国内覆盖最广、认可度最稳的「通用核心」，约 3 年更新一次       |
| CSSCI（南大核心 / C 刊）          | 南京大学                  | 人文社科               | 社科领域天花板；另分「扩展版」与「集刊」，认可度依次降低      |
| CSCD（中国科学引文数据库）        | 中国科学院文献情报中心    | 理工医                 | 分核心库 / 扩展库，被称为「中国的 SCI」                       |
| 双核心（北核 + 南核）             | —                         | 全学科                 | 同时被两套目录收录，国内认可度最高                            |

#### 国际体系

| 名称                 | 归属            | 说明                                                                 |
| -------------------- | --------------- | -------------------------------------------------------------------- |
| SCI / SCIE           | 科睿唯安        | 自然科学、工程技术、医学，全球理工科顶流检索体系                     |
| SSCI                 | 科睿唯安        | 社会科学（经济、管理、教育、心理、社会学等）                         |
| A&HCI                | 科睿唯安        | 艺术与人文                                                           |
| ESCI                 | 科睿唯安        | SCI 的「预备役」，**没有影响因子**，国内多数单位暂不视同 SCI         |
| EI                   | 爱思唯尔        | 工程技术领域。**必须区分 EI 期刊（JA，源刊）与 EI 会议（CA）**，认可度相差极大 |
| Scopus               | 爱思唯尔        | 覆盖面比 Web of Science 更广，自有 CiteScore / SJR 指标              |
| CPCI（原 ISTP）      | 科睿唯安        | 专收会议论文，分 CPCI-S（理工）与 CPCI-SSH（社科），认可度逐年下降   |
| DOAJ                 | 瑞典隆德大学    | 开放获取（OA）期刊目录，用于筛选正规 OA 期刊                         |

::: warning 最容易踩的两个坑

**坑一：EI 会议 ≠ EI 源刊**。「EI 源刊（JA）」是期刊论文，「EI 会议（CA）」是会议论文，两者在毕业、职称认定上常常一个认可、一个不认可。

**坑二：ESCI ≠ SCI**。ESCI 是预备目录、无影响因子，花着 SCI 的钱发 ESCI 并不划算。

:::

### 1.3 分区与指标：「一区」到底指什么

「一区」「Q1」「影响因子 8.0」是评价体系里最高频的词，但它们的对象是**期刊**，不是某一篇论文。

**影响因子（Impact Factor, IF）**：某期刊前两年发表的论文，在统计年度被平均引用的次数。IF 高说明这本期刊整体引用表现好，**但不能推断里面每一篇都优秀**。判断一篇论文值不值得读，最终还是要回到它的问题、方法、证据和结论。

**JCR 分区（Q1–Q4）**：科睿唯安在《期刊引用报告》中把同一学科类别内的期刊按指标排序，平均分成四等份，前 25% 为 Q1。注意一本期刊可能同时属于多个学科，**在不同学科里的分区可能不同**，所以看到「一区」最好再确认是哪个学科类别。

**中科院分区（1–4 区）**：国内另一套体系，把期刊分为 13 个大类，1 区为影响因子前 5%，2 区 6%–20%，3 区 21%–50%，4 区之后。它的算法与 JCR 不同，同一本期刊「JCR 是 Q1、中科院不一定是 1 区」是常态。所以有一条很实用的经验：**看到「一区」，先问清是 JCR 分区还是中科院分区。**

**其他常见指标**：

- `CiteScore`、`SJR`：Scopus 体系的期刊指标；
- `H 指数（h-index）`：一个研究者至少有多少篇论文被引用了至少多少次，衡量个人产出与影响力的组合指标；
- `被引次数 / 高被引论文`：单篇或单作者层面的引用数据，ESI 会据此划分高被引论文、热点论文。

不同单位的要求差别很大，常见的说法是理工科博士毕业需要 1–2 篇 SCI（或 1 篇 SCI + 1 篇 EI / 核心），人文社科常要求 CSSCI，而**具体标准一定要以本校本学院的文件为准**，不要只听师兄师姐转述。

### 1.4 计算机与 AI 领域的特殊规则：CCF 列表与顶会文化

计算机、人工智能方向还有一套行业内的「评级」：**CCF 推荐国际学术会议和期刊目录**，由中国计算机学会发布，分 A、B、C 三类。

- `CCF-A` 类顶会 / 顶刊（如 NeurIPS、ICML、ICLR、CVPR、ACL、AAAI、OSDI、SOSP、SIGIR、WWW 等）在行业内的含金量往往超过多数 SCI 期刊，是保研、求职、申博的硬通货；
- 计算机领域大量重要工作**先投会议、同时挂 arXiv 预印本**，评审意见在 OpenReview 上公开，形成「arXiv → 会议 → 期刊扩展版」的固定工作流；
- 因此检索时，只看「期刊」会漏掉最前沿的一部分，**会议论文库（如 DBLP、OpenReview）必须一起查**。

### 1.5 OA、APC 与「水刊」「预警期刊」

**OA（Open Access，开放获取）**：读者可免费阅读全文的出版模式。很多 OA 期刊向作者收取文章处理费（APC，Article Processing Charge）。但要注意：**并非所有 OA 期刊都收费，也不是所有非 OA 期刊都不向作者收费**；OA 描述的只是获取方式，不是质量等级。

**「水刊」**是口语化说法，通常指发表门槛低、审稿不严或学术认可度低的期刊，但**没有全国统一的判断线**，不能简单把「审稿快」「影响因子低」「收版面费」等同于水刊。

**掠夺性期刊（predatory journal）**：以收钱为目的、缺乏真实同行评审与规范编辑流程的期刊。识别思路：查国家新闻出版署、查 CN / ISSN、查是否被主流数据库收录、看出版机构与编委、看是否出现在**预警名单**（如中国科学院发布的《国际期刊预警名单》）上。投稿前多查一步，比发表后才发现成果无法认定要划算得多。

### 1.6 常用科研工具及其功能

工具不是越多越好，按「科研流程」分阶段配置一套顺手的即可。

#### ① 文献管理（最该先装的一个）

| 工具        | 价格              | 特点                                                   |
| ----------- | ----------------- | ------------------------------------------------------ |
| Zotero      | 免费开源          | 浏览器插件抓取题录、PDF 关联、Word 插件插引文、标签分组、云同步；社区插件丰富 |
| EndNote     | 付费（学校常购买） | 老牌、引用格式模板多、去重与大规模库管理强             |
| Mendeley    | 免费（有付费版）  | PDF 批注方便，兼具学术社交属性                         |
| NoteExpress | 付费（学校常购买） | 中文支持好，符合国内使用习惯                           |

核心功能就四件事：**抓题录、管 PDF、插引文、自动生成参考文献表**。配套的还有 `BibTeX / .bib`、`.ris`、`.enw` 等题录格式（LaTeX 用 BibTeX 管理参考文献）。

#### ② 阅读与笔记

- PDF 阅读批注：Adobe Acrobat、PDF Expert、MarginNote（可把批注转成思维导图 / 记忆卡）；
- 知识管理：Obsidian（本地 Markdown + 双向链接 + 知识图谱）、Notion（数据库 + 多视图）、OneNote、Evernote；
- 笔记方法：卡片笔记法（Zettelkasten，一张卡只记一个原子知识点，用链接把卡片连起来）、康奈尔笔记法（主笔记区 + 关键词栏 + 总结栏）。

#### ③ 写作与排版

- `Word`：通用，多数中文期刊与学位论文模板基于它；
- `LaTeX` / `Overleaf`：公式与交叉引用友好，大量期刊提供 LaTeX 模板，Overleaf 支持在线协作与版本历史；汇报 PPT 可用 LaTeX 的 `Beamer` 包；
- `BibTeX`：参考文献的几种写法与格式；
- 语法与润色：Grammarly、DeepL、各类学术润色服务（**注意 AI 可以帮整理格式，但不能替你证明一篇文献真实存在**）。

#### ④ 数据分析与统计

| 工具      | 定位                                        |
| --------- | ------------------------------------------- |
| Python    | NumPy / Pandas / Scikit-learn / PyTorch，机器学习与数据分析主流 |
| R         | 统计计算与绘图（ggplot2），生物信息、计量经济常用 |
| MATLAB    | 矩阵运算、仿真、信号与图像处理              |
| SPSS      | 图形界面统计，问卷与行为研究常用            |
| Stata / SAS | 社会科学、医学统计                        |

#### ⑤ 绘图与可视化

- 数据图：`Origin`（学术老牌，模板多）、`GraphPad Prism`（生命科学首选，自带统计）、Python 的 `Matplotlib / Seaborn / Plotly`、R 的 `ggplot2`；
- 示意图 / 流程图：`Adobe Illustrator`、`Inkscape`（开源）、`Visio`、`draw.io`（在线免费）、`BioRender`（生命科学图标库）、`ChemDraw`（化学结构式）；
- 网络图 / 地理图：`Gephi`、`QGIS / ArcGIS`；
- 仪表盘 / 交互图：`Tableau`、`Power BI`、`Datawrapper`、`Flourish`。
- 通用规范：印刷用图分辨率不低于 300 DPI、字体统一、优先导出矢量格式（PDF / EPS / SVG）。

#### ⑥ 编程与工程环境

`VSCode + Anaconda`（环境与包管理）、`Linux`（远程服务器训练）、`Git / GitHub`（版本控制与协作）、`Jupyter Notebook`（可复现的分析文档）。做图学习 / 深度学习还会用到 `PyTorch`、`PyTorch Geometric (PyG)` 等。

#### ⑦ AI 辅助科研工具

眼下这类工具可以按「你愿意花多少精力折腾」分成三组，各取所需：

- **编程型**（Claude Code、Codex）：能读写本地文件、跑命令、把重复工作自动化，自由度高但对新手门槛也高；
- **开箱即用型**（YILA 等）：内置模型与学术工作流，直接做文献检索、综述、数据分析、绘图、学术 PPT；
- **本地 DIY 型**（WorkBuddy 等）：装在电脑上，处理本地文件与办公任务，用 Skill 扩展能力，适合愿意折腾配置的人。

需要补一句：AI 可以大幅提效，但**文献的真实性、数据的真实性、引用的规范性必须自己核对**，学术诚信是不可触碰的红线。

#### 一张「按阶段选工具」的速查表

| 科研阶段     | 主要任务                     | 推荐工具                                             |
| ------------ | ---------------------------- | ---------------------------------------------------- |
| 查文献       | 检索、追踪、去重             | Google Scholar、Web of Science、Scopus、CNKI、Connected Papers |
| 读文献       | 批注、笔记、知识沉淀         | Zotero + PDF 阅读器、Obsidian、Notion                |
| 做研究       | 写代码、跑实验、版本管理     | VSCode、Anaconda、Linux、Git / GitHub、Jupyter       |
| 分析数据     | 统计、建模                   | Python、R、MATLAB、SPSS、Stata                        |
| 画图         | 数据图、示意图               | Origin、GraphPad Prism、Matplotlib / ggplot2、Illustrator |
| 写论文       | 排版、引用、润色             | Word、LaTeX / Overleaf、BibTeX、Grammarly            |
| 汇报交流     | 组会 PPT、海报、演讲         | PowerPoint、Beamer、Canva                             |

## 二、科研「黑话」

每个圈子都有行话，科研圈的行话尤其多，因为很多概念来自英文、又被中文口语二次加工过。下面按主题整理，看不懂时回来查即可。

### 2.1 论文与发表

| 黑话                     | 含义                                                                 |
| ------------------------ | -------------------------------------------------------------------- |
| **大论文**               | 硕士 / 博士学位论文。要完整呈现研究问题、文献综述、理论框架、方法、过程与结论，申请学位时需通过评审和答辩 |
| **小论文**               | 在读期间写作或发表的期刊论文、会议论文。不是严格学术名称，是否要求发表、发几篇，**以本校本届培养方案为准** |
| 一稿多投                 | 同一篇稿子同时投给多个期刊 / 会议。属于学术不端，会进黑名单           |
| 查重                     | 检测文字重复率。学位论文与投稿前一般都要过这一关                     |
| 盲审 / 外审 / 送审       | 送出给校外专家匿名评审。分单盲（作者不知评审人）与双盲（双方互不知情） |
| 返修（大修 / 小修）      | 审稿意见要求修改。`major revision` 大修、`minor revision` 小修        |
| 录用（Accepted）         | 稿件被编辑部接受                                                     |
| 见刊 / 在线发表          | 见刊是正式印在期刊某一期；`ahead of print` 是先在线发表再排期        |
| 撤稿（Retraction）       | 因错误或学术不端撤回已发表论文，影响很严重                           |
| 勘误（Corrigendum / Erratum） | 更正已发表论文中的错误，作者造成用 Corrigendum，出版方造成用 Erratum |
| 拒稿 / 桌拒              | 被拒；`desk reject` 指编辑初审阶段就退稿，未送外审                   |
| 正刊 / 增刊 / 专刊 / 特刊 | 增刊、专刊的认可度通常低于正刊，投稿前务必确认学校认定规则           |

### 2.2 身份与角色

| 黑话              | 含义                                                                 |
| ----------------- | -------------------------------------------------------------------- |
| 老板              | 导师。前加「大 / 小」：大老板通常是课题组负责人（PI），小老板是协助带学生的年轻老师 |
| PI / 独立 PI      | Principal Investigator，课题负责人；「独立 PI」指能独立带组、说了算的导师 |
| 大牛 / 小牛       | 领域内成果多、头衔多的资深学者 / 正在成长的青年学者                   |
| 青椒              | 高校青年教师的谐音，取「青涩」与「焦虑」两层意思，是压力最大的群体之一 |
| 土博 / 海龟       | 本土博士 / 海外归国博士（海归）                                       |
| 博士後（薄厚）    | Postdoc，博士后，处于学生与教师之间的过渡岗位                         |

## 三、文献资料检索：去哪找、怎么找

检索要回答两个问题：一是「我该找什么」，二是「我该去哪儿找」。前者是关键词问题，后者是数据库问题。两者都对了，检索才是体力活而不是碰运气。

### 3.1 检索前的准备：关键词四步法

1. **确定关键词**：先从核心概念出发，明确研究对象、研究问题、研究方法，提取 3–5 个关键词。
2. **拆分研究主题**：把主题拆成「研究对象 A / B / C + 研究方法」这样的组合。例如生态恢复方向可拆成研究对象（生态恢复、草场退化……）、关联对象（气候变化、降水、气温……）、研究方法（遥感、遥感分类、定量反演……）。
3. **扩展关键词**：在拆分结果之上分三个层次发散——**范畴细化（下一层）、范畴泛化（上一层）、同范畴内找近义词与反义词**。扩展既要靠逻辑，也要靠领域积累。
4. **重组并试验**：把重组后的关键词与逻辑关系丢进数据库搜索引擎，必要时反复扩展、重组、再试验。

### 3.2 数据库地图：先知道去哪找

#### 中文数据库

| 数据库          | 定位与特点                                                       |
| --------------- | ---------------------------------------------------------------- |
| CNKI 中国知网   | 国内最大的综合性学术资源库，收录文献总量超 2 亿篇，含北大核心期刊与 1915 年以来的历史文献 |
| 万方数据        | 期刊 + 学位论文 + 专利 / 标准 / 法规的综合平台，部分文献与知网互补 |
| 维普            | 核心期刊收录率高的中文综合库                                     |

#### 综合型引文数据库

| 数据库          | 特点                                                                 |
| --------------- | -------------------------------------------------------------------- |
| Web of Science  | 收录标准严格、引用数据成熟，含 SCIE / SSCI / A&HCI / CPCI / ESCI，是做文献综述与引用分析的「干净结果池」 |
| Scopus          | 覆盖面通常比 Web of Science 更广，含 CiteScore / SJR，适合第二轮补充与跨学科扩展 |
| Google Scholar  | 覆盖最广的学术搜索引擎，含期刊、会议、学位论文、预印本、技术报告；适合第一轮「看全景」，但结果较杂 |

#### 专业与领域数据库

| 领域         | 数据库                                                        |
| ------------ | ------------------------------------------------------------- |
| 医学 / 生物  | PubMed、PubMed Central（PMC）、bioRxiv、medRxiv               |
| 计算机 / 电子 | IEEE Xplore、ACM Digital Library、DBLP、Papers with Code、OpenReview |
| 出版商全文   | SpringerLink、ScienceDirect、Wiley、JSTOR                     |
| 心理学 / 教育 | PsycINFO、ERIC                                                |
| 社科 / 经济  | SSRN、RePEc                                                    |

#### 预印本、引文图谱与其他入口

- **预印本服务器**：`arXiv`（数理、计算机）、`bioRxiv / medRxiv`（生物医学）、`SSRN`（社科）、`ChemRxiv`（化学）、`PsyArXiv`（心理）。在快速发展的领域，预印本常常比正式发表领先数月甚至一年以上。
- **引文图谱 / 文献发现**：`Connected Papers`、`Research Rabbit`、`Litmaps`、`Semantic Scholar`——输入一篇种子论文，自动找出引用它和被它引用的相关论文，形成引文网络；Semantic Scholar 还能区分「高影响力引用」并生成摘要。
- **开放获取与数据托管**：`DOAJ`（OA 期刊目录）、`CORE`、`Zenodo`（可为数据集 / 代码分配 DOI）、`OSF`、`FigShare`。
- **学术社交**：`ResearchGate`、`Academia.edu`（可直接向作者索取全文）；国内还有 `X-MOL`、`小木虫`。
- **中文阅读辅助 / 文献工具**：知网研学、各类文献翻译与笔记插件。

::: warning 关于免费全文

部分第三方站点（如 Sci-Hub）能以「免费下载」为卖点获取付费论文，但涉及版权与合规风险，不建议作为常规依赖。正规路径是：**通过学校图书馆的数据库权限下载**，或向作者邮件索取、查找预印本 / 机构仓库版本。

:::

### 3.3 高级检索语法（重点）

高级检索是所有数据库的通用能力，掌握下面四类语法，检索效率会明显不同。

#### ① 布尔逻辑（Boolean）

| 运算符      | 作用                 | 示例                        |
| ----------- | -------------------- | --------------------------- |
| `AND`       | 缩小范围，两项都出现 | `深度学习 AND 医学图像`     |
| `OR`        | 扩大范围，命中任一   | `青少年 OR 大学生 OR 本科生` |
| `NOT`       | 排除                 | `人工智能 NOT 机器人`       |

中文库里通常写作「并且 / 或者 / 不含」，效果相同。注意：**多个运算符混用时要用括号明确优先级**，否则系统会按默认顺序（Web of Science 是 NOT → AND → OR）执行。

#### ② 精确匹配与通配符

- `"machine learning"`：双引号做**精确短语**匹配。副作用是**会关闭词形还原**（plural / 时态 / 英美拼写不再自动合并）。
- `*`：右截词，替代零个或多个字符，如 `nanotub*` 匹配 nanotube、nanotubes。
- `?`：有限截词，替代恰好一个字符；`??` 替代两个。
- `$`：替代零个或一个字符，如 `colo$r` 可匹配 color 与 colour。
- 词形还原（lemmatization）：Web of Science 在主题 / 标题检索中默认开启，自动匹配单复数（含 tooth / teeth 这类不规则变化）、动词时态与比较级。

#### ③ 邻近算符

| 算符        | 作用                                                         |
| ----------- | ------------------------------------------------------------ |
| `NEAR/n`    | 两词之间最多间隔 n 个词，顺序不限，如 `biologist NEAR/5 relationship`；不写 n 时默认 15 |
| `SAME`      | 仅用于地址字段，要求两词出现在同一个地址中，如 `AD=("Family Medicine" SAME McGill)` |
| `AROUND(n)` | 部分平台（如 Google 系）支持的邻近检索，任一词序、最多间隔 n 词 |

#### ④ 字段限定：把检索词「钉」在正确的位置

**Web of Science 常用字段标识**：

| 标识              | 含义                     | 标识              | 含义           |
| ----------------- | ------------------------ | ----------------- | -------------- |
| `TS=`             | 主题（标题+摘要+关键词） | `TI=`             | 标题           |
| `AU=`             | 作者                     | `AD=`             | 地址 / 机构    |
| `SO=`             | 出版物名称（期刊名）     | `PY=`             | 出版年         |
| `DO=`             | DOI                      | `SU=`             | 研究方向       |
| `IS=`             | ISSN / ISBN              | `DT=`             | 文献类型       |
| `ALL=`            | 所有字段                 | `#n`              | 引用检索结果集 |

**其他平台的字段限定**：

- **Google Scholar**：`intitle:`（标题）、`author:`（作者）、`source:`（来源期刊）、`filetype:pdf`（文件类型）、`site:.edu`（限定站点）、`-word`（排除）。
- **PubMed**：`[Title/Abstract]`、`[Author]`、`[MeSH Terms]`（医学主题词，用受控词表自动涵盖同义词与下位概念）、`2020:2026[dp]`（出版年）。
- **CNKI 高级检索**：可选择主题 / 篇名 / 关键词 / 摘要 / 作者 / 来源等字段，并可叠加来源类别（如「北大核心」「CSSCI」）等限定。

#### ⑤ 可以直接抄的检索式示例

```text
# Web of Science：图神经网络 & 联邦学习，2020 年以来的期刊论文
TS=("graph neural network*" OR GNN) AND TS=(federated OR "edge computing") AND PY=(2020-2026) AND DT=Article

# Web of Science：清华大学某作者 2024 年的文章
AU=(Zhang W*) AND AD=(Tsinghua Univ*) AND PY=2024

# Google Scholar：标题含 VLA、排除综述、只要 PDF
intitle:"vision-language-action" -review filetype:pdf

# PubMed：深度学习用于影像学的文献（受控词 + 时间限定）
("deep learning"[Title/Abstract]) AND (radiology[MeSH Terms]) AND 2020:2026[dp]

# 中文库（示意图）：主题 = 图神经网络 且 联邦学习，来源限定北大核心
主题 = 图神经网络 AND 联邦学习  AND  来源类别 = 北大核心
```

::: tip 检索的基本节奏：先宽后窄

先用较宽的检索式摸清文献总量和关键词分布，再逐步加限定词收窄；**不要一上来就把所有条件堆满**，否则很容易一条结果都没有。结果出来后按「相关性最强 / 最近更新 / 影响力最大（引用数、期刊影响因子）」排序择优，先判断哪些值得下载、值得精读。

:::

### 3.4 从检索到入库：引文追踪与文献库管理

检索只是第一步，真正拉开差距的是**如何把文献组织成一个持续增长的结构**。

- **引文追踪**：从一篇高质量论文出发，用「被引（Cited by）」向前追新进展，用「参考文献（References）」向后追理论源头，用「相关文章（Related）」横向找同类工作。这是把单篇种子扩成一整个研究网络的最快方法。
- **设置快讯（Alert）**：在 Google Scholar、Web of Science 上保存检索式或订阅关键词提醒，让新论文主动找上门。
- **文献库分层**：把文献分成两个库分别维护——**基础文献库**（领域经典、理论根基）与**引用文献库**（准备写进自己文章的、精确到句子级别支撑的文献），再配合文献管理软件批量编辑题录、统一引用格式。
- **结果评价的三个维度**：相关性（是否真的强相关）、时效性（尽量用最近更新的版本，同时区分「更新认识」与「首创出处」）、影响力（引用数、期刊指标，但不必迷信单一数字）。

### 3.5 阅读方法：变速阅读与三遍阅读法

文献那么多，读法要有轻重缓急。

**变速阅读**：

- **高速阅读（泛读 / 筛读）**：快速浏览标题、摘要、图片摘要、亮点、关键词、高频词、图表、公式、参考文献，顺带留意期刊、作者、机构。目的是对下载的文献做二次筛选，挑出最值得读的几篇。
- **变速阅读（跳读）**：用 PDF 全文检索定位关键词，只深入读局部，锁定关键情节，节省精力。
- **低速阅读（精读）与互动阅读**：精读要理解细节与逻辑；互动阅读指带着批判思维「隔空对话作者」——找茬、纠错、赞赏，力图达到精神交流的效果。这种力度需要训练。

**三遍阅读法**：

1. 第一遍（5–10 分钟）：读标题和摘要，浏览结构，看结论，判断是否值得继续；
2. 第二遍（20–30 分钟）：读引言了解背景与问题，看图理解方法，重点读结果与讨论，标记关键信息与疑问；
3. 第三遍（1–2 小时）：逐段精读，分析方法优缺点、创新性与局限，与自己的研究建立联系，写详细笔记。

**为什么阅读在于分享**：交流能赋予知识生命，分享会反过来促进自己的学习。另有一个「对称写作法」值得留意——论文的引言与讨论在结构上是对称的（引言用演绎法推导研究问题，讨论用归纳法比较相关研究），读文献时留意这种对称，写自己的文章会更加顺畅。

## 结语

把这三块补上，科研才从「跟着感觉走」变成「知道自己在做什么、要去哪里找、该怎么表达」。如果只记三句话：

1. **分清对象**：SCI / CSSCI 是索引，北大核心 / 中科院分区是目录与分区，影响因子是期刊的平均引用表现——它们都不能直接等于某一篇论文的质量。
2. **术语是路标**：知道大论文 / 小论文、纵向 / 横向、顶会 / 顶刊、大修 / 小修、一稿多投，和师兄师姐、导师沟通时就不会错频。
3. **检索是手艺**：布尔逻辑 + 字段限定 + 邻近算符 + 引文追踪，再配一套文献管理工具，就能把「找文献」从碰运气变成可复现的流程。
