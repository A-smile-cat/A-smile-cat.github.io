计算机领域的文献检索，绕不开两大出版机构的官方平台：**ACM Digital Library**（ACM 数字图书馆，dl.acm.org）和 **IEEE Xplore**（ieeexplore.ieee.org）。前者收录 ACM 出版的全部期刊与会议，后者承载 IEEE 的期刊、会议、标准与电子书。计算机领域分量最重的一批出版物——ACM 的 TOCS、TOSEM、JACM，IEEE 的 TPAMI、TC、TMC——都只在这两个平台上提供正式电子版。

入门01 介绍过通用的检索思路（布尔逻辑、字段限定、引文追踪），这一篇落到两个平台本身：各自收录什么、检索界面怎么用、没有订阅权限时如何合法获取全文，以及哪些个人化功能值得注册账号去开启。

## 一、两个平台各是什么

### 1.1 ACM Digital Library（dl.acm.org）

ACM Digital Library 是 ACM（Association for Computing Machinery，国际计算机学会）的官方在线平台，收录 **ACM 出版的全部文献全文**：SIGCOMM、MobiCom、SOSP 等会议论文集，TOCS、TOSEM 等期刊，以及 ACM 的杂志与通讯。

它还深度集成了一层更广的索引——**ACM Guide to Computing Literature**：一个横跨各大出版商的计算文献书目库。也就是说，在 ACM DL 检索时，结果可能同时包含 ACM 全文和其它出版社（如 IEEE、Elsevier）文献的题录信息。理解这个双层结构很重要：

- 搜到的 ACM 文献：机构有订阅即可下载全文；
- 搜到的非 ACM 文献：只有题录（标题、作者、摘要、引文信息），全文需要跳转到相应平台获取。

平台自带完整的文献计量（bibliometrics）数据：每篇文章的引用数与下载量持续统计，期刊、会议、作者均有计量档案。

### 1.2 IEEE Xplore（ieeexplore.ieee.org）

IEEE Xplore 是 IEEE（电气电子工程师学会）的官方文献平台，收录范围比 ACM DL 更宽：

| 内容类型 | 说明 |
| -------- | ---- |
| 期刊与杂志 | TPAMI、TC、TPDS、TMC 等全部 IEEE 期刊 |
| 会议论文集 | INFOCOM、CVPR 等 IEEE 主办会议 |
| 标准 | IEEE 行业标准全文（如网络、电气标准） |
| 电子书 | Wiley-IEEE、MIT Press 等合作出版的技术书籍 |
| 在线课程 | IEEE 的英文学习资源 |

IEEE Xplore 的检索默认覆盖**元数据**（标题、作者、摘要、关键词等），并可扩展到全文检索；平台还提供作者档案、机构档案、引文追踪等工具，是 IEEE 系文献唯一权威的在线来源。

### 1.3 一个方向性的记忆法

简单说：**ACM 出的文献去 ACM DL 找，IEEE 出的文献去 IEEE Xplore 找**。SIGCOMM 的论文集只在 ACM DL，INFOCOM 的论文集只在 IEEE Xplore；TON 这类 IEEE/ACM 联合出版的期刊，两个平台都有收录。检索前先想清楚目标期刊/会议的出版社，能省一半弯路。

## 二、ACM DL 的功能与用法

### 2.1 检索：基本检索与高级检索

首页搜索框即基本检索，输入关键词回车即可。要精确控制时，点导航栏的 **Advanced Search**（或结果页顶部的 Edit Search），可用这些手段收窄结果：

- **Search Within**：限定检索词出现在哪个字段——标题、作者、摘要、全文等；
- **范围切换**：只搜 ACM 全文，还是连同 Guide to Computing Literature 的书目一起搜；
- **Filters**：按出版物、ACM 计算分类体系（CCS）主题词、出版社、资助机构、artifact 徽章过滤；
- **Publication Date**：限定最近一个月/半年/一年，或自定义日期区间；
- 支持布尔运算符 `AND` / `OR` / `NOT`，右侧面板有检索语法提示；
- 页面底部可以把当前查询语法**导出为 CSV**，方便复现检索式——写综述时按「检索式—命中数」记录检索过程，这个导出很有用。

### 2.2 文章页：引文导出、提醒与收藏

进入任何一篇文章的页面，摘要上方有三个灰色图标，对应三个高频动作：

- **引号图标——导出引文**：可下载或复制该文完整的引用信息，格式支持 **BibTeX、EndNote、ACM Ref**。写论文配参考文献时，直接取 BibTeX 条目粘进 `.bib` 文件即可；
- **铃铛图标——被引提醒**：订阅后每当这篇文章被新文献引用，平台发邮件通知。做相关工作追踪时，给自己领域的几篇关键文献都挂上提醒；
- **文件夹图标——存入 Binder**：把文献存进个人文件夹（Binder），可建多个分类管理；Binder 还支持一键生成 PDF（发送到账号邮箱），包含全部已存文献的书目信息与可用全文。

### 2.3 个人账号值得开启的功能

注册免费的 ACM Web 账号后可以：保存检索式（下次直接重跑）、管理 Binder 与提醒、维护个人主页关联的发表列表。检索历史与保存的检索式是长期课题的「检索资产」，别每次都从零开始搜。

## 三、IEEE Xplore 的功能与用法

### 3.1 检索：四个入口

IEEE Xplore 的检索入口比 ACM DL 多，分工明确：

- **Global Search（一框式检索）**：首页大搜索框。默认搜元数据；多个检索词之间默认 `AND` 关系；自动匹配词根变化（复数、时态、英美拼写差异），所以输入 robot 也能命中 robots；
- **Advanced Search（高级检索）**：结构化界面，用下拉菜单把检索词限定到具体字段（标题、作者、出版物名称、摘要等），适合精确组合；
- **Command Search（命令检索）**：自由文本写检索式，支持嵌套逻辑，例如 `"Abstract":ofdm AND "Publication Title":communications`——熟悉语法后这是效率最高的方式；
- **Citation Search（引文检索）**：已知卷期、页码、年份等线索时，用它们直接定位具体条目。

### 3.2 检索语法要点

IEEE Xplore 的检索运算符有一条硬规则：**布尔与位置运算符必须全部大写**——`AND`、`OR`、`NOT`、`NEAR`、`ONEAR`。其余要点：

- 双引号 `" "` 精确匹配短语：`"Power Consumption"` 不会拆成两个词；
- 通配符：`*` 匹配多个字符（`secur*` 命中 security、securing……），`?` 匹配单个字符；
- 检索词不区分大小写，但运算符必须大写。

### 3.3 结果页：二次过滤与排序

结果页顶部有 **Search Within Results**（在结果中再检索），左侧是 **Facets** 过滤面板：年份、作者、机构、会议/期刊类型、My Subscribed Content（只看有权限的内容）等。排序方式可切换：最新优先、被引最多（论文或专利引用）等——找「领域权威文献」用被引排序，追「最新进展」用时间排序。

文章页里值得留意的区块：**References**（参考文献，可跳原文）与 **Cited By**（被引情况，向上追踪）；**Keywords**（作者关键词 + IEEE 关键词 + 动态索引词）；以及新上线的**图像搜索**——可以直接检索论文中的图表、原理图、流程图，找「某类方法的典型架构图」时很方便。

### 3.4 提醒系统：Search Alerts 与 Content Alerts

IEEE Xplore 的追踪功能比 ACM DL 更体系化，核心是两种提醒（注册免费个人账号后可用）：

- **Search Alerts（检索提醒）**：把一个调好的检索式保存为提醒，之后有符合条件的新文献入库就发邮件。管理入口在 My Settings → Alerts → Saved Searches，最多保存 15 个检索式，可以只关邮件但保留检索式；
- **Content Alerts（内容提醒）**：直接追踪某本期刊/会议/标准/电子书，新卷期出版即收到目录（Table of Contents）通知。追 TPAMI、TMC 这类月刊的新作，这个功能比手动刷网页可靠得多。

此外，个人账号还支持创建文件夹分类管理文献、查看检索历史、收藏常用期刊封面。

## 四、没有订阅权限怎么办

两个平台都是订阅制，校外或非订阅机构用户会遇到全文墙。合法获取的常见途径：

1. **机构订阅 + 校园网/VPN**：绝大多数高校图书馆采购了两平台（或至少其一）的订阅。校外先连学校 VPN 或使用图书馆提供的远程访问入口，认准 IP 已在订阅范围内；
2. **图书馆文献传递**：图书馆没订的文献，可通过馆际互借/文献传递服务申请，通常免费或低价；
3. **开放获取（Open Access）版本**：不少作者会把预印本传到 arXiv 等仓库，或论文本身是 OA 出版的。ACM 也在推进 Open 模式，部分新文献已开放阅读；
4. **作者主页与机构仓库**：会议论文常在作者个人主页提供合法自存档版本；
5. **单篇购买**：两平台都支持单篇在线购买，应急可用，但价格不低，优先走前面几条路。

注意：不要使用来路不明的「破解全文」渠道，既违法又常有安全风险。

## 五、实用工作流建议

把两个平台的能力串成日常流程：

1. **定检索式**：在 Advanced Search 里用字段限定 + 布尔逻辑把检索式调到查准与查全的平衡点，ACM DL 可导出查询语法留档；
2. **挂提醒**：检索式存为 Search Alert（IEEE Xplore），关键文献挂被引提醒（两平台都支持），期刊挂 Content Alert；
3. **边读边收**：读到的文献随手进 Binder（ACM DL）或个人文件夹（IEEE Xplore），引文直接导出 BibTeX 喂给文献管理工具；
4. **两条引文链**：每篇核心文献都向下看 References、向上看 Cited By，把「一篇」扩展成「一串」；
5. **权限先行**：换环境（假期离校、换机构）先确认访问通道，避免在全文墙前干等。

## 六、结语

1. **按出版社找平台**：ACM 文献在 ACM DL，IEEE 文献在 IEEE Xplore，联合出版物两边都有；ACM DL 的 Guide 层还能顺带检索其它出版社的题录。
2. **检索是门手艺**：字段限定、布尔运算（IEEE 的运算符要大写）、通配符与精确短语，加上结果页的 Facets 二次过滤，比单纯堆关键词高效得多。
3. **让平台替你盯梢**：检索提醒、被引提醒、期刊目录提醒，三件套挂好之后，新文献会主动找上你；BibTeX 导出和 Binder/文件夹则负责把读过的东西沉淀下来。
